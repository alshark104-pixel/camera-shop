# 📷 Camera Shop - موقع شركة الكاميرات

موقع حديث واحترافي لشركة بيع الكاميرات، يتضمن متجر إلكتروني وقسم نكات طريفة يومية!

## ✨ الميزات

### 1. **عرض المنتجات**
- عرض جميل للكاميرات الاحترافية
- تصميم responsive يعمل على جميع الأجهزة
- بطاقات منتجات بمعلومات كاملة والسعر

### 2. **نظام النكات العشوائي** 😂
- دمج **Official Joke API** الخارجي
- نكات برمجية طريفة جديدة في كل مرة
- زر نسخ النكتة للمشاركة بسهولة
- تحميل ديناميكي مع مؤشر تحميل

### 3. **نموذج الاتصال**
- نموذج للتواصل مع الشركة
- تصميم سهل الاستخدام

### 4. **التصميم الحديث**
- تدرجات لونية جميلة
- تأثيرات حركية سلسة
- دعم كامل للعربية (RTL)

## 🚀 كيفية الاستخدام

### طريقة 1: فتح الملف محلياً
```bash
1. انسخ المستودع
2. افتح ملف index.html في المتصفح
3. استمتع بالموقع!
```

### طريقة 2: استخدام GitHub Pages
```bash
1. اذهب إلى Settings في المستودع
2. اختر Pages من الجانب الأيسر
3. اختر Branch: main
4. الموقع سيكون متاح على: https://yourusername.github.io/camera-shop
```

## 🔗 APIs المستخدمة

### Official Joke API
- **الرابط:** https://official-joke-api.appspot.com
- **الاستخدام:** جلب نكات برمجية عشوائية
- **النقطة المستخدمة:** `/jokes/programming/random`
- **البيانات المرجعة:**
  ```json
  {
    "type": "general",
    "setup": "سؤال النكتة",
    "punchline": "الإجابة الطريفة",
    "id": 1
  }
  ```
